# نئوکور — فرانت‌اند فروشگاه قطعات کامپیوتر

فرانت‌اند React (Vite) برای فروشگاه لپ‌تاپ، کارت گرافیک، هارد، مانیتور، کیبورد،
ماوس، هدفون، هاب و کیس گیمینگ شیشه‌ای. طراحی بر پایه تم تیره با لهجه‌ی نئون
(فیروزه‌ای/بنفش) و فونت وزیرمتن برای فارسی.

## اجرا

```bash
npm install
npm run dev
```

پروژه روی `http://localhost:5173` بالا می‌آید.

## ساختار

```
src/
  components/     کامپوننت‌های صفحه اصلی (Navbar, Hero, CategoryGrid, ...)
  data/
    mockProducts.js   داده‌ی نمونه — دقیقاً به شکلی که API جنگو باید برگردونه
  index.css       توکن‌های رنگ/تایپوگرافی و استایل پایه
  App.jsx         چیدمان صفحه اصلی
```

## اتصال به بک‌اند Django REST

فعلاً همه‌چیز از `src/data/mockProducts.js` می‌خونه. وقتی API جنگو آماده شد:

1. در `App.jsx` (یا با یه هوک جدا مثل `useProducts`) به‌جای ایمپورت مستقیم از
   `mockProducts.js`، یه `fetch` یا `axios` به اندپوینت واقعی بزن، مثلاً:

   ```js
   fetch("http://localhost:8000/api/products/")
     .then((res) => res.json())
     .then(setProducts);
   ```

2. شکل داده‌ی برگشتی از API باید با شکل فیلدهای `mockProducts.js` یکی باشه
   (`id`, `name`, `category`, `brand`, `price`, `old_price`, `rating`,
   `review_count`, `badge`, `specs`) تا کامپوننت‌ها بدون تغییر کار کنن.

3. برای دسترسی فرانت (روی پورت 5173) به بک‌اند جنگو (روی پورت 8000)، پکیج
   `django-cors-headers` رو روی بک‌اند فعال کن.
